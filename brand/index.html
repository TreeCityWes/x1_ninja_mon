Principle

Interface cyan

#00B8FF is the only interactive brand color on the site. Selected filters, search focus, Submit Token, and active nav all use it — often as a 15–25% wash with a solid cyan border.

Identity navy

The mark is a deeper X1 blue: #003A93 → #0078C0. That gradient is for the X, the headband, and the “X1” letters. It is not a text or link color.

Rules

Do

  • Keep chrome ≥90% void and steel. Cyan is a reticle, not a fill.
  • Use cyan for selected, focus, links, and the one primary action.
  • Set black type on solid cyan buttons.
  • Reserve green / red for price direction.
  • Stay dark. Match theme-color: #0A0A0F.

Don’t

  • Drop in Tailwind sky/blue defaults in place of #00B8FF.
  • Put white type on cyan fills.
  • Use logo navy for links or small labels.
  • Warm the grays or add a light theme.
  • Promote #39FF14 — it is a leftover, not a token.
